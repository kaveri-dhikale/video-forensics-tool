# Video Forensics and Analysis System

A Python-based video forensics application
built using Streamlit and OpenCV.

## Features
- Video metadata analysis
- SHA-256 file hashing
- Video anomaly checks
- PDF forensic report generation
- Simple Streamlit interface
- No FFprobe dependency

## Technologies
- Python
- Streamlit
- OpenCV
- NumPy
- ReportLab

## Installation

Install dependencies:

pip install -r requirements.txt

## Run the Application

streamlit run app.py

## Disclaimer
This project is intended for educational
and research purposes. Results are not
conclusive proof of video tampering.
